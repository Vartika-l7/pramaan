# PRAMAAN Engineering Decisions Log

Every architectural decision, removal, or archive move is recorded here with its reason.

| Date | Component | Decision / Change | Why | What Was Removed or Moved |
| :--- | :--- | :--- | :--- | :--- |
| 2026-11-24 | `backend/app/main.py` | Removed `StaticFiles` mount for `/assets` and catch-all SPA fallback (`/{full_path:path}`) that served `frontend/dist/index.html`. | Visiting `http://127.0.0.1:8000/` served a stale pre-redesign build of `frontend/dist/` (last built `2026-11-19 20:18:25`), causing users to see the OLD UI on port 8000 while seeing the NEW UI on port 5173. | Removed `StaticFiles`, `FileResponse`, `HTTPException` SPA fallback lines 86–99 in `backend/app/main.py`. |
| 2026-11-24 | `backend/app/main.py` | Backend now serves **only** `/api/*` endpoints, `/docs`, `/api/health` (returning app version + resolved absolute paths), and a small JSON notice at `/` pointing to `http://localhost:5173`. | Establishes a single source of truth: port 8000 is the API server and port 5173 is the frontend UI dev server. Prevents stale HTML from ever masking live frontend code. | Replaced HTML fallback at `/` with JSON `{message, ui, docs, health}`. |
| 2026-11-24 | `backend/app/main.py` | Added startup port-in-use guard (`_check_port_free`) and startup path banner (`_print_startup_paths`). | Makes it obvious at startup which database, evidence store, and keys directory the backend is using, and fails fast with a clear message if port 8000 is already occupied. | None (addition). |
| 2026-11-24 | `frontend/dist/` | Archived stale built frontend directory instead of deleting it. | The `frontend/dist/` build from `2026-11-19 20:18:25` (`index-BTn5FG_x.js`, `index-CWGnNtpH.css`) contained the pre-phase UI and was being served by FastAPI. Moving it preserves history without risking accidental serving. | Moved `frontend/dist/` → `_old_project_archive/frontend_dist_stale/dist/`. Added `_old_project_archive/` to `.gitignore`. |
| 2026-11-24 | `scripts/dev.py`, `scripts/status.py` | Added cross-platform Python scripts to launch both servers together (`scripts/dev.py`) and inspect listening ports + `/api/health` (`scripts/status.py`). | Gives one repeatable way to run and diagnose the full stack on Windows, macOS, and Linux without guessing commands or ports. | None (addition). |
| 2026-11-24 | `README.md` | Documented exact ports (`8000` backend API, `5173` frontend UI), `scripts/dev.py`, `scripts/status.py`, and production build commands. | Eliminates ambiguity between old single-port instructions and the clean API/UI split. | Replaced old single-port `http://127.0.0.1:8000` UI instructions in `README.md`. |
| 2026-11-24 | `pytest.ini`, `tests/conftest.py` | Added global 60s per-test timeout (`pytest-timeout==2.4.0`), `slow`/`llm`/`integration` markers, `--run-slow`/`--run-llm` flags, `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`, `PRAMAAN_FAKE_LLM=1`, session-scoped `synthetic_dataset_dir`, and autouse `isolated_storage_env`. | Prevents infinite hangs, eliminates 60+ second closed-port Ollama timeouts during tests, prevents accidental HuggingFace downloads, and isolates every test into temp storage. | Added `pytest.ini`, `tests/conftest.py`, and `pytest-timeout==2.4.0` in `requirements.txt`. |
| 2026-11-24 | `tests/test_phase2c_assistant.py` | Added `test_live_ollama_provider_optional` marked `@pytest.mark.llm` (skipped by default unless `--run-llm` is passed). | Keeps real Ollama connectivity testable on demand without slowing or flaking offline default test runs. | Marked 1 new test `llm` (skipped unless `--run-llm`). |
| 2026-11-24 | `tests/test_phase1_hardening.py` | Scaled `test_kat_streaming_vs_oneshot_large_file_and_os_tool` to 32 MB by default (200 MB with `--run-slow`) and `test_property_single_byte_mutation_fails_verification` to 25 seeded examples by default (100 with `--run-slow`). | Keeps default test runs fast while preserving full 200 MB and 100-example stress checks under `--run-slow`. | None (behavior gated by `--run-slow`). |
| 2026-11-24 | `backend/app/ai/provider.py`, `backend/app/api/system.py`, `backend/app/db.py` | Enforced 2s connect timeout on all Ollama HTTP calls, added `PRAMAAN_FAKE_LLM=1` fast-path to `DeterministicProvider`, and set SQLite `timeout=3.0` + `PRAGMA busy_timeout = 3000`. | Fails fast instead of blocking on closed ports or SQLite locks. | Replaced 15s SQLite timeout and unconfigured httpx timeouts. |
| 2026-11-24 | `scripts/run_all_checks.py` | Replaced stdlib `trace.Trace` with `pytest-cov` (in `--full` mode), added `--fast` and `--full` modes, per-stage elapsed timers, global timeouts, and a guaranteed summary table even on failure/timeout. | Stdlib `trace.Trace` caused 20x–50x Python slowdown across the entire suite. `--fast` now completes in ~76s and `--full` in ~232s. | Removed stdlib `trace.Trace` coverage wrapper; skipped `npm run build` in `--fast` mode (runs in `--full`). |
| 2026-11-24 | `redesign_spec.txt`, `.coverage` | Removed obsolete scratch spec `redesign_spec.txt` from repository root and cleaned temporary `.coverage` file. | `redesign_spec.txt` was an unreferenced pre-redesign scratch file cluttering the repo root; `.coverage` is a transient pytest-cov artifact. | Removed `redesign_spec.txt` and `.coverage`. |
